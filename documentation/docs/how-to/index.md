# How-to guides

Recipes for specific tasks, assuming you know the basics (see the [tutorials](../tutorials/index.md) otherwise).

- [Add Kt-Math as a dependency](add-kt-math-as-a-dependency.md): Gradle (multiplatform, Native, JVM), Maven, npm.
- [Parse and convert numbers](parse-and-convert-numbers.md): from strings and Kotlin numbers, among the three types.
- [Control precision and rounding](control-precision-and-rounding.md): `MathContext`, `RoundingMode`, scales.
- [Use big-math](use-big-math.md): logarithms, roots, powers, trigonometric functions, constants.
- [Call Kt-Math from C](call-kt-math-from-c.md): the conventions of the C API, and building the shared library.
- [Contribute](contribute.md): build, test and document Kt-Math itself.
